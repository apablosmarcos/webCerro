# Higienextremadura modernization reference pack

This pack preserves the current site's verified content, visual evidence, and source assets before design begins. It is reference material only; no new-site implementation or reuse permission is implied.

## Review path

1. Read the [content inventory](content-inventory.md) for business copy, catalog data, source URLs, contradictions, and validation warnings.
2. Read the [brand audit](brand-audit.md) for verified identity signals and the boundary between brand, content, and Joomla template styling.
3. Review the [asset manifest](../../assets/source-site/manifest.md), downloaded source files, and desktop screenshots.

## Confirm with the client before design

- [ ] **Identity and legal details:** legal entity name, NIF/CIF, registered address, domain ownership, privacy controller, and current RGPD/LOPDGDD text.
- [ ] **Current contact data:** which address is public, whether the warehouse address is current, whether `927 419 291` remains active, and whether `676 193 667` and `josemiguel@higienextremadura.com` are the preferred channels.
- [ ] **Image rights:** ownership or licenses for the logo, slides, corporate/editorial photographs, category images, and any supplier catalog media.
- [ ] **Claims and certifications:** evidence and approved wording for environmental, quality, cost, performance, disinfection, bactericidal/fungicidal, H.A., and hospital-registration claims.
- [ ] **Desired catalog depth:** category-only overview, complete reference catalog, selected products, downloadable supplier catalogs, or an enquiry-led catalog; also confirm current products, codes, formats, and supplier relationships.
- [ ] **Primary CTA:** phone, email, quote request, contact form, WhatsApp, visit, or another measurable action.

## Known decision blockers

The current site mixes `.com` and `.es`, publishes three location/address contexts, relies on outdated privacy language, mentions a form that is not present, duplicates catalog code `10040`, and provides no evidence for several commercial/regulatory claims. Resolve these points rather than silently carrying them into the redesign.
